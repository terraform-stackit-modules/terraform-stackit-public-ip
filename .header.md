# Terraform STACKIT Public IP module

Terraform module which reserves [STACKIT public (floating) IPs](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/public_ip) and optionally associates existing ones to network interfaces on [STACKIT](https://www.stackit.de/en/).

This repository is not from the official STACKIT organization.

## Usage

```hcl
module "public_ip" {
  source  = "terraform-stackit-modules/public-ip/stackit"
  version = ">= 1.0.0"

  project_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"

  # Reserve public IPs (optionally attached to a NIC).
  public_ips = {
    floating = {}                                              # a floating IP
    web = {
      network_interface_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
    }
  }

  # Associate an ALREADY-EXISTING public IP to a NIC (do not also manage it via public_ips).
  public_ip_associations = {
    legacy = {
      public_ip_id         = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
      network_interface_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
    }
  }
}
```

See [`examples/basic`](./examples/basic) for a self-contained example (requires only `project_id`).

## Notes

- **Do not mix** `public_ips` and `public_ip_associations` for the same public IP or the same
  network interface — the STACKIT provider warns this leads to conflicts because both would own
  the IP↔NIC association.
- Both inputs are maps keyed by a **stable identifier**.
- When a public IP is attached implicitly by another resource (e.g. a Kubernetes Load Balancer),
  use `lifecycle { ignore_changes = [network_interface_id] }` in your root module to avoid drift.

### Contributing

This module follows the conventions of the `terraform-stackit-modules` organization. Before opening a PR:

1. [Install pre-commit](https://pre-commit.com/#install) and run `pre-commit install`.
2. Install the required tools: [tflint](https://github.com/terraform-linters/tflint), [tfsec](https://aquasecurity.github.io/tfsec/), [terraform-docs](https://github.com/terraform-docs/terraform-docs), [golang](https://go.dev/doc/install), [coreutils](https://www.gnu.org/software/coreutils/).

## Terratest

The `test/` directory holds a Terratest integration test that applies the `examples/basic` root module against a real STACKIT project (requires `STACKIT_SERVICE_ACCOUNT_KEY` and `STACKIT_PROJECT_ID`).

```bash
cd test
go mod init github.com/terraform-stackit-modules/terraform-stackit-public-ip
go get github.com/gruntwork-io/terratest@v1.0.1
go mod tidy
go test -v -timeout 45m ./...
```
